# joluisaponte.github.io

Personal site and journal, built with Jekyll and GitHub Pages.

## Run locally

Use Ruby 3.2 or newer. If you use rbenv, activate it in your shell first:

```sh
eval "$(rbenv init - zsh)"
ruby -v
```

From this directory:

```sh
gem install bundler:4.0.3
bundle install
bundle exec jekyll serve --livereload
```

Open http://localhost:4000. Stop the server with Ctrl+C.

## Edit the site

- Homepage: `index.md`
- Shared layouts: `_layouts/`
- Styles: `assets/css/site.css`
- Journal entries: `_posts/YYYY-MM-DD-title.md`
- Navigation and site settings: `_config.yml`

Edit source files; `_site/` is generated by Jekyll. Restart the server after changing `_config.yml`.

To check a production build:

```sh
JEKYLL_ENV=production bundle exec jekyll build
```
